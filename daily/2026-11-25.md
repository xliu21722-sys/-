# 编导乐园每日简报 2026-11-25

## Codex CLI 新增线程跳转与命令补全

OpenAI Codex CLI 支持从搜索结果/对话记录中点击跳转至保存的会话和嵌套 Agent，并支持 Tab 补全 slash 命令参数。

来源 GitHub · 一手
https://github.com/openai/codex/releases/tag/rust-v0.172.0

和你有什么关系：为阿伟实测 AI 工具链中的 CLI 类 Agent 提供可验证的交互增强能力，可直接用于办公自动化工作流调试与技能封装。

## vLLM 首日支持百度 ERNIE 5.5 Flash 预览版

vLLM 通过 vLLM-ERNIE 插件在 0.32.0 版本中实现对 ERNIE 5.5 Flash 的开箱即用支持，含结构感知核融合、FlashIndexer 等加速技术。

来源 官方博客 · 一手
https://vllm.ai/blog/2026-11-24-ernie-5-5-flash-preview

和你有什么关系：为阿伟评测国产大模型落地性能提供关键基础设施参考，尤其适用于需本地部署/私有化推理的企业提效场景。

## vLLM-GR 发布：面向生成式推荐的高效推理框架

vLLM-GR 扩展 vLLM 支持生成式推荐模型，引入加速器端 beam search、目录约束与候选路径共享 KV 缓存。

来源 官方博客 · 一手
https://vllm.ai/blog/2026-11-24-vllm-gr-announcement

和你有什么关系：拓展阿伟对企业级 AI 应用边界的认知，尤其适用于电商、SaaS 类中小企业构建个性化推荐工作流。

## MoRI UMBP 将 Agent KV 缓存移至 NVMe，大幅降本

在 AMD MI355X GPU 上，NVMe 存储的 MoRI UMBP KV 池性能媲美同容量 DRAM，单日 Agent 缓存成本远低于传统方案。

来源 官方博客 · 一手
https://vllm.ai/blog/2026-11-23-skip-the-dram-tier

和你有什么关系：为阿伟分析小企业 AI 系统部署成本提供新视角，支撑‘零代码搭系统’中对硬件性价比与长时态 Agent 架构的设计判断。
