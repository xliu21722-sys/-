# 编导乐园每日简报 2026-11-26

## Codex CLI 新增线程跳转与命令补全功能

Codex CLI 支持从搜索结果/转录文本中点击跳转至保存的对话和嵌套 Agent，并支持 Tab 补全 slash 命令参数。

来源 GitHub · 一手
https://github.com/openai/codex/releases/tag/rust-v0.172.0

和你有什么关系：直接提升阿伟实测 AI 工具时的终端操作效率，尤其适用于构建和调试基于 CLI 的自动化工作流（如 Agent 编排、日志分析脚本）。

## vLLM 首日支持百度 ERNIE 5.5 Flash Preview

vLLM 通过 vLLM-ERNIE 插件（vllm==0.32.0）实现对 ERNIE 5.5 Flash 的开箱即用支持，含结构感知核融合、FlashIndexer 等加速技术。

来源 官方博客 · 一手
https://vllm.ai/blog/2026-11-24-ernie-5-5-flash-preview

和你有什么关系：为阿伟实测国产大模型推理性能提供可复现的技术路径，支撑其在‘AI 产品实测’支柱中对比千问/讯飞/ERNIE 的本地部署成本与延迟。

## vLLM 发布生成式推荐专用推理引擎 vLLM-GR

vLLM-GR 新增加速生成式推荐任务的能力，支持加速端 beam search、目录约束与候选路径共享 KV 缓存。

来源 官方博客 · 一手
https://vllm.ai/blog/2026-11-24-vllm-gr-announcement

和你有什么关系：拓展阿伟对企业 AI 提效内容的覆盖边界——中小电商/内容平台可借该工具零代码接入生成式推荐能力，契合‘小公司降本’与‘零代码搭系统’方向。
